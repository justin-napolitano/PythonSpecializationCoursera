This repo contains Python exercises from the Coursera Python Specialization. It's a dive into programming concepts, data structures, file handling, and hands-on projects like API usage and image processing.

## Key Features

- Basics: loops, conditionals, lists, dictionaries.
- Projects organized by course modules.
- Practical work: file I/O, web APIs, data parsing.
- Algorithms: Fibonacci, frequency analysis.
- External libraries: requests, PIL, OpenCV, pytesseract, kraken.

## Getting Started

### Prerequisites

- Python 3.6+
- pip

### Installation

1. Clone the repo:
   ```bash
   git clone https://github.com/justin-napolitano/PythonSpecializationCoursera.git
   cd PythonSpecializationCoursera
   ```

2. (Optional) Set up a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Windows: venv\Scripts\activate
   ```

3. Install dependencies (create `requirements.txt` based on imports):
   ```bash
   pip install -r requirements.txt
   ```

## Running the Code

Run scripts directly from course folders:
```bash
python Week3Assignment.py
```

Ensure any necessary data files and API keys are properly set up.
